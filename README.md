# Sales Performance Dashboard - Power BI

## Overview
This project demonstrates the creation of an interactive Power BI dashboard using a sales dataset containing 500 records.

## Dashboard Visuals

- Monthly Sales Trend (Line Chart)
- Category-wise Sales Comparison (Column Chart)
- Sales Performance vs Target (Gauge Chart)
- Sales Distribution by Region (Donut Chart)
- Sales by Region (Map)

## DAX Measures

```DAX
Total Sales =
SUM(SalesAmount)

Total Target =
SUM(TargetSales)

Total Orders =
COUNT(OrderID)
```

## Tools Used

- Power BI Desktop
- CSV Dataset
- DAX

## Key Insights

- Analyzed monthly sales performance.
- Compared sales across categories.
- Measured sales against targets.
- Examined regional sales distribution.
